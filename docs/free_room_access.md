# 随意进出会议室权限

预约结束撤销门禁权限时，同时满足以下条件的参与者会保留该房间的已有门禁权限：

- 房间的「是否可被随意进出」（`Room.allow_free_access`）已开启。
- 参与者账号具有「随意进出会议室」（`Appointment.can_access_rooms_freely`）权限。

用户权限通过现有 `has_perm` 检查，支持直接授权、用户组授权和权限黑名单。其他参与者继续按原有规则撤销权限；后续进行中的重叠预约仍按原有逻辑保留门禁。

## 上线配置

1. 执行 `python manage.py migrate`，应用 `Appointment.0009_room_allow_free_access`，并生成新权限。
2. 在后台「用户」或「组」中授予「随意进出会议室」权限。
3. 在后台「房间」中打开相应会议室的「是否可被随意进出」。该字段支持列表编辑和筛选。
4. 重启预约任务所在进程，使任务使用新的撤销逻辑。

所有现有房间的开关默认关闭，不根据历史门禁数据推断授权。该权限与预约权限独立，需要预约的账号仍须拥有原有预约权限。

此功能仅防止预约结束时撤销已有门禁权限。首次授予账号权限或开启房间开关，不会自动向门禁设备下发授权；需要通过现有门禁授权流程完成。关闭开关或收回用户权限也不会立即同步撤销设备权限，后续预约结束时会按当时配置处理。

## 回归验证

在配置完整的开发环境执行 `python manage.py test Appointment.tests`。测试模拟海康 SDK，使用测试数据库验证权限组合、用户组、黑名单、重叠预约、多个门禁以及撤销失败时的预约状态。
